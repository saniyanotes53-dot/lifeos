# Life OS — Backend Functions & Setup Guide

This folder contains the backend Cloud Functions for:
1. **AI Insights** (`generateInsights` HTTPS Callable) using Google Gemini
2. **Email Gateway** (`onUserCreated`, `weeklyDigest`, `monthlyDigest`) integrated with Firebase Trigger Email extension
3. **Push Reminders** (`checkTimetableReminders`) scheduled every 15 minutes with FCM Admin SDK

---

## 1. Secrets & Gemini API Key Setup

Store your Gemini API key securely in Google Secret Manager via Firebase CLI:

```bash
firebase functions:secrets:set GEMINI_API_KEY
```
*(Paste your free Gemini API key when prompted).*

---

## 2. Deploying Cloud Functions

From the `lifeos/` directory:

```bash
firebase deploy --only functions
```

Note: Deploying Cloud Functions requires the Firebase project to be on the pay-as-you-go **Blaze plan** (which includes generous free tier limits: 2M invocations/mo, free Secret Manager calls).

---

## 3. Firebase Trigger Email Extension Setup

1. In the Firebase Console, go to **Extensions** → search for **Trigger Email** (`firestore-send-email`).
2. Click **Install**.
3. Configure your SMTP provider (e.g. SendGrid free tier, Mailgun, or standard SMTP).
4. Set the collection path to `mail` (default).
5. All welcome emails, weekly digests, and monthly digests generated by the functions will automatically be sent out!
